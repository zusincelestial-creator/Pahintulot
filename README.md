# Celestial Messenger Control

Unang bukas ng domain: gumawa ng dashboard password, tapos paste cookie, Save & connect, pili ng GC, Start.
Optional: Volume sa /app/data (o DATA_DIR) para di mawala ang cookie/password sa redeploy.
Edit replies.json para sa reply pool.
